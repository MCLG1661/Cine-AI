# 🎬 Cine AI

**Streaming Experience powered by AI**

CineAI é uma aplicação Front-End inspirada em plataformas de streaming, desenvolvida com **HTML, CSS e JavaScript**, utilizando **Inteligência Artificial como copiloto durante o processo de desenvolvimento**.

O projeto nasceu como evolução de uma experiência prática realizada durante a **Imersão Front-End na Era da IA, da Alura**, e foi posteriormente reconstruído com identidade própria para integrar meu portfólio de projetos em tecnologia.

---

## 🚀 Objetivo

O objetivo do CineAI é desenvolver uma experiência moderna de navegação por filmes e séries, aplicando conceitos de desenvolvimento Front-End e explorando como ferramentas de Inteligência Artificial podem apoiar diferentes etapas da construção de uma aplicação.

Além do aspecto visual, o projeto busca trabalhar:

* organização de código;
* responsividade;
* manipulação do DOM;
* interatividade com JavaScript;
* armazenamento local;
* experiência do usuário;
* uso de IA como apoio ao desenvolvimento.

---

## ✨ Funcionalidades

O projeto será desenvolvido de forma incremental.

### Primeira versão

* 🎥 Filme ou série em destaque
* 🎬 Catálogo de títulos
* 🗂️ Organização por categorias
* 🔎 Busca por filmes e séries
* 🎭 Filtro por gênero
* ❤️ Minha Lista / Favoritos
* 💾 Persistência com `localStorage`
* ℹ️ Modal com informações do título
* 📱 Layout responsivo

### Evoluções planejadas

* sistema de recomendações;
* consumo de API externa de filmes;
* personalização da experiência;
* recursos assistidos por Inteligência Artificial.

## 🤖 Inteligência Artificial no desenvolvimento

A Inteligência Artificial é utilizada como ferramenta de apoio ao processo de desenvolvimento, contribuindo para atividades como:

* ideação de funcionalidades;
* estruturação da aplicação;
* análise de código;
* debugging;
* melhorias de UX/UI;
* refatoração;
* documentação.

O objetivo não é apenas gerar código com IA, mas utilizá-la como **copiloto de desenvolvimento**, mantendo compreensão sobre a lógica e as tecnologias implementadas.
